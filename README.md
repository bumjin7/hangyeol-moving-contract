# 한결이사 계약서 PWA

- Firebase/Google 계정 연결 없음
- 계약서는 해당 휴대폰 브라우저의 localStorage에 저장
- 홈 화면 설치 가능한 PWA
- 한결이사 로고 및 업체 정보 적용
- 담당자: 정병국
- 우리은행 1002-130-158228 / 예금주 정병국

## 실행
1. Node.js 설치
2. `npm install`
3. `npm run dev`

## 배포
Vercel 등에 프로젝트 폴더 전체를 배포한 후, 갤럭시 Chrome/삼성 인터넷에서 사이트를 열고 `홈 화면에 추가` 또는 `앱 설치`를 선택합니다.

## 주의
계약서 데이터는 휴대폰 로컬 저장소에만 있으므로 브라우저 데이터 삭제/앱 데이터 초기화 시 사라질 수 있습니다.
